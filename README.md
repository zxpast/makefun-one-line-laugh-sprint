A make.fun entry for the **One-Line Laugh Sprint** competition
(`u-daring-gecko-25-one-line-laugh-sprint-cda708b2`).

`main.ts` (Node 22, stdlib only) writes one original funny line about
everyday life — at most 200 characters — to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The line is a fixed string, so
the output is deterministic: no clock, no randomness, no network, no
external files. A code-point gate throws if the line falls outside 1–200.
